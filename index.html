Welcome to the Software Engineering Bootcamp

This OER bootcamp course provides instruction in full stack web application development using modern JavaScript technologies. Students design, implement, and deploy web based solutions while applying AI assisted development tools in an ethical and effective manner. The curriculum emphasizes problem solving, system design, teamwork, and industry standard best practices, with dedicated focus on cloud native development—including containerization, distributed services, and modern deployment pipelines—as well as API first architecture, enabling students to build scalable, maintainable, and interoperable applications aligned with current industry expectations.

This OER course is structured into six modules, each focusing on essential concepts and practical skills in modern full-stack web development with AI assistance. Each module includes lectures, hands-on labs, and projects that allow students to apply their knowledge in real-world scenarios. The curriculum emphasizes problem-solving, system design, teamwork, and industry-standard best practices, with dedicated focus on cloud-native development—including containerization, distributed services, and modern deployment pipelines—as well as API-first architecture, enabling students to build scalable, maintainable, and interoperable applications aligned with current industry expectations. The six modules are as follows:

  • Module 1: Source Control and Modern Web Foundations with AI Assistance
  • Module 2: JavaScript Fundamentals with AI-Assisted Learning
  • Module 3: JavaScript DOM and Events: Building Interactive Web Interfaces with AI Support
  • Module 4: ReactJS and Component-Based UI Development with AI Assistance
  • Module 5: Advanced React: Routing, State Management and API-First Front-End Architecture
  • Module 6: Node.js Asynchronous Programming, Server Development and Cloud-Native Foundations

Each module includes corresponding chapters, hands-on laboratory exercises, and projects designed to reinforce key concepts and provide opportunities for practical application. Throughout the OER, AI-assisted learning activities guide students in using AI tools effectively to understand programming concepts, solve problems, develop applications, and strengthen their independent learning skills.

A Note from the Authors:

This Open Educational Resource (OER) project was developed to provide comprehensive lecture materials and hands-on laboratory exercises for students with little or no prior experience in full-stack web development using HTML, CSS, JavaScript, and JavaScript frameworks. Each chapter and lab exercise incorporates AI-assisted learning to help students use AI tools effectively and responsibly while developing functional web applications. The materials are designed to guide learners step by step, building their foundational knowledge, practical programming skills, and confidence in application development. This OER covers essential concepts in a clear, accessible, and student-friendly format, supporting meaningful learning through hands-on practice and AI-enhanced instruction.

Learning Outcomes

Upon successful completion of this bootcamp, students will be able to:
  • Apply principles of software development to design and implement full stack web applications using JavaScript technologies.
  • Analyze computing problems and identify appropriate front end, back end, API, and data solutions within a modern web architecture.
  • Design and evaluate web based systems that meet specified functional and technical requirements, including API first service design and scalable cloud native application structures.
  • Use AI assisted development tools responsibly to improve efficiency, debugging, testing, documentation, system design, and code quality while adhering to ethical guidelines.
  • Demonstrate effective teamwork, version control, and professional communication in a collaborative development environment.
  • Apply industry best practices related to security, testing, deployment, maintainability, and cloud native development workflows.
  • Develop and deploy containerized applications using cloud native concepts such as Docker, Kubernetes fundamentals, microservices decomposition, and continuous integration/continuous delivery (CI/CD).
  • Create, document, and integrate API first architectures using standards such as REST and OpenAPI, ensuring interoperability, reusability, and alignment with modern distributed systems.
