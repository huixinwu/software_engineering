Module 6: Node.js Asynchronous Programming, Server Development and Cloud-Native Foundations

Week 13, 14, and 15 — Node.js Asynchronous Programming, Server Development and Cloud-Native Foundations

This module explores how modern backend applications are built using Node.js, with a focus on asynchronous programming and scalable server architecture. Learners will understand how JavaScript handles asynchronous operations using callbacks, promises, and async/await to build efficient, non-blocking applications.

The module also covers creating servers with Node.js, introducing core concepts such as request handling, routing, and basic backend service structure. AI-assisted coding techniques are integrated to help learners recognize patterns, generate optimized solutions, and improve debugging efficiency.

In addition, learners are introduced to foundational cloud-native concepts, including containerization. They will gain an understanding of how modern applications use containers and microservices to improve scalability, portability, and resilience in distributed systems.

Duration: 9 hours

Topics:
  • React Router for multi-page navigation
  • State management techniques
  • API first front end consumption (understanding how UI depends on well designed APIs)
