Module 1: Source Control and Modern Web Foundations

Week 1-2— Source Control & Foundations

This module introduces the core practices of web development workflow and design fundamentals, enhanced with AI-powered support. Learners begin by understanding source control principles to manage and track changes effectively in development projects. They then move into building structured webpage layouts using HTML, leveraging AI tools to accelerate learning, improve code quality, and generate semantic structures efficiently. The module also explores intelligent styling techniques, where AI is used to assist in mastering CSS layout design, responsiveness, and visual hierarchy. By the end of the module, learners will be able to create well-structured, styled web pages while incorporating AI as a practical development companion for both coding and design decisions.

Duration: 9 hours

Topics:
  • Source control (Git, GitHub)
  • HTML layout design (with AI assistance)
  • CSS responsive design (with AI assistance)
Chapters
  • Chapter 1: Creating Webpage layout using HTML and AI support
  • Chapter 2: Intelligent Styling: Using AI to Master layout styling
Labs:
  • Lab 0: GitHub repository setup
  • Lab 1: HTML structure and CSS styling with AI assistance
